# Project rename: inference-router → accounts-proxy (2026-10-16)

[Plan amendment R](../plans/2026-10-16-00-08-model-catalog-docs-plan.md#5-amendment-r--project-rename-2026-10-16).
The user asked on 2026-10-16 to rename everything, from the directory to every acronym, from `inference-router` to
`accounts-proxy`, with `ap` as the prefix of the opencode provider ids. Decisions (all as recommended):

| # | Decision |
|---|---|
| Q1 | Scope B: the product name, every identifier built from it, and the generic word "router" (`x-proxy-*` headers, `/proxy/v1/models`, `proxy.yaml`, `apps/proxy`, `bun run proxy`, "proxy token", the `ap_` derived session prefix). |
| Q2 | History keeps the old name: dated plans, research, reference records, the session record, git history, recorded provider exchanges (`tests/fixtures/captures/`) and vendored sources. Live documents link to the two historical files whose names carry it (`2026-10-06-00-23-inference-router-plan.md`, `2026-10-05-20-07-llm-router-from-auth-plugins.md`); those names stay. |
| Q3 | No compatibility with the old names: no fallback data directory, no old environment variables. |
| Q4 | `login opencode` is run once more (the Console client id changes); the OpenAI account is kept (it already has its issued client id). |
| Q5 | The GitHub repository and the local directory are renamed. |
| Q6 | The Hindsight memory bank keeps its existing name through a `mapPathToBank` entry in the user's own configuration. |

## Name map

Applied by [`scripts/evidence/rename-project.ts`](../../scripts/evidence/rename-project.ts) `--apply` to every tracked
file and path except the historical ones (Q2). Generated model data (`builtin-models.ts`,
`builtin-model-reference.ts`, header `// GENERATED by scripts/evidence/gateway-snapshots.ts`) gets the product names only:
the vendors' model names and descriptions use the word "router" for their own products (e.g. OpenRouter's
"Auto Router"), which are data, not this project. `OpenRouter`/`openrouter` is a provider and is never mapped.

| Old | New | Replacements |
|---|---|---|
| `inference-router` (incl. `@inference-router/…`) | `accounts-proxy` | 1438 |
| `INFERENCE_ROUTER` (every environment variable) | `ACCOUNTS_PROXY` | 153 |
| `Inference Router` | `Accounts Proxy` | 2 |
| `ir-` (opencode provider ids `ir-<provider>`) | `ap-` | 35 |
| `rtr_` (rule Z24 derived session prefix) | `ap_` | 10 |
| `router` / `Router` (not after `open`/`Open`; e.g. `x-router-lossy`, `routerLog`, `RouterError`) | `proxy` / `Proxy` | 512 / 133 |

236 files rewritten, 58 paths moved (`apps/router/` → `apps/proxy/`, `config/router.example.yaml` →
`config/proxy.example.yaml`, `packages/core/src/ports/outbound/router-token.ts` → `proxy-token.ts`,
`tests/support/e2e/router-process.ts` → `proxy-process.ts`, `apps/proxy/tests/e2e/router-edges.test.ts` →
`proxy-edges.test.ts`).

**Mechanical proof.** `rename-project.ts --check` maps the old and the new spelling of every name to one neutral token
in HEAD and in the working tree and requires equality for every changed file and path; a moved path must be exactly
the map of its old path; a historical file must be unchanged. Result: `241 changed paths checked, 0 failures`.
`bun.lock` was renamed by the same map; after deleting every `node_modules` a fresh `bun install` produced a
byte-identical lockfile (`cmp`), and `bun install --frozen-lockfile` reports no changes.

**Hand edits after the mechanical stage** (so `--check` now names exactly these files besides this record):
AGENTS.md §7 (the name law), README.md (rename note), the plan's amendment R, the session record, the dated
amendments at the end of the three rules documents (model catalog, gateway, OpenAI plan usage), and one e2e assertion
in `apps/proxy/tests/e2e/gateways.test.ts`: the device-login page is the Console's own `verification_uri_complete`,
replayed from a capture recorded before the rename, so the test now reads it from that capture (the first e2e run after
the mechanical stage failed there, 217 pass / 1 fail); the `client_id` the proxy sends is asserted in the request body.

**Permanent check.** `tests/arch/legacy-names.test.ts` (part of the architecture tier of `bun run verify`) fails when
a tracked path or live file carries the former product name, its environment prefix, the generic word or the `rtr_`
prefix outside the historical files; it carries its own self-test.

## Values sent upstream

| Value | Where | Effect |
|---|---|---|
| OpenCode Console `client_id` = `accounts-proxy` | device login and every renewal (rules Z17, Z18) | the stored Console sign-in was issued to the former id; `login opencode` once more (Q4) |
| OpenAI `agent_name_hint` = `accounts-proxy` | first sign-in only (rules S2, S3) | the active account keeps its issued client id; the consent screen shows the new name on `login openai --new` |
| OpenRouter key label and headless redirect (`urn:accounts-proxy:openrouter:headless`) | key creation only | the stored key is unaffected |
| `User-Agent: accounts-proxy/0.1.0` | OpenAI and OpenCode requests | checked live |

Claude and Antigravity send no project name. The vendored plugin and opencode sources contain none and stay
byte-identical. The recorded exchanges keep the values that were sent when they were recorded; the replay server
answers by method and path, so the e2e tests replay them unchanged.

## User steps (R7)

1. Stop the daemon (Ctrl-C).
2. `mv ~/.local/share/inference-router ~/.local/share/accounts-proxy` and
   `mv ~/.local/share/accounts-proxy/router.yaml ~/.local/share/accounts-proxy/proxy.yaml`; the old `logs/router.log`
   stays as history, the new log is `logs/proxy.log`.
3. From `/home/mavasbel/Dev/repos/accounts-proxy`: `bun run proxy serve`.
4. `bun run proxy login opencode`.
