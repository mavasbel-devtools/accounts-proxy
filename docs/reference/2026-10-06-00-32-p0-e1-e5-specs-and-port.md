## E5 — Default listen port: **4141**

The ports were measured on 2026-10-06 00:14.
- **Not listening.** `netstat -ano -p tcp` lists no listener on 4141, on any address.
- **Not excluded.** `netsh int ipv4 show excludedportrange protocol=tcp` reserves 1462, 5357, 50000-50059 (administered), 52686-53385, 57143-57242, 57405-57504, 57549-57648, 59896-59995 and 65236-65335. 4141 is in none of these ranges.
- **Why 4141.** It is below the Windows dynamic range (49152-65535), which is where Hyper-V/WSL reservations land at boot.

**Startup rule:** the daemon binds exactly the configured port. `EADDRINUSE` is a fatal, named error. It never falls back to another port silently.
